# Introducción compacta del catálogo por línea

El hero fotográfico de pantalla completa del catálogo por línea se reemplazó
por una introducción editorial compacta para priorizar el acceso a tipologías,
filtros y productos.

- Se retiraron el breadcrumb y el botón redundante para desplazarse al catálogo.
- El nombre, subtítulo y descripción de la línea se presentan sobre una
  superficie clara.
- El catálogo técnico es la única acción de la introducción y solo aparece
  cuando existe una URL válida.
- La imagen administrable conserva proporción `4/3`, se presenta como contenido
  editorial en desktop y no se renderiza visualmente en mobile.
- El skeleton replica la nueva composición para mantener estable el layout.
