# Catálogos y especificaciones técnicas

La biblioteca técnica reúne dos funciones bajo una misma ruta pública, separadas
mediante tabs de shadcn:

- **Catálogos:** documentos PDF administrados por línea, con búsqueda, estado y
  acceso externo.
- **Especificaciones:** documentos PDF técnicos por línea, con el mismo modelo
  de versión, fecha, disponibilidad y acceso externo.

Cada línea incorpora campos independientes para la URL, versión y fecha del
documento de especificaciones. Los campos son opcionales para conservar
compatibilidad con líneas existentes y mostrar el estado “En preparación” hasta
que el documento sea publicado en Supabase.

La vista pública no infiere resistencia, tolerancias ni ensayos desde los
productos comerciales: esa información se consulta únicamente desde el PDF
técnico respaldado por el fabricante.
