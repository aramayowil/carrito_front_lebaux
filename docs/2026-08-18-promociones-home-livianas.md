# Promociones de Home más livianas

La sección de promociones reduce adornos para priorizar fotografía, producto y
precio vigente.

- El encabezado utiliza “Oportunidades” y “Precios especiales”.
- Las imágenes adoptan proporción 4:3, con zoom mínimo al pasar el cursor.
- Cada card conserva una sola etiqueta promocional, línea, nombre, precio
  promocional, precio anterior y CTA.
- Se eliminan gradientes, sombras, descripción extensa, badges secundarios y
  textos sobre cantidad de combinaciones.
- En teléfonos el carrusel muestra una card completa; pasa a dos, tres y cuatro
  cards mediante breakpoints semánticos.
- Las flechas se reservan para desktop y no se muestran cuando existe una sola
  promoción.
- El skeleton promocional replica la nueva proporción y densidad de contenido.
