# Promociones de Home con proporción compacta

La fotografía de las promociones adopta una proporción 4:3 para reducir la
altura total de las tarjetas. Se mantiene de borde a borde y conserva todo el
ancho disponible, pero permite recorrer la sección con mayor rapidez tanto en
desktop como en mobile.

El estado de carga utiliza la misma proporción para evitar saltos de layout.
