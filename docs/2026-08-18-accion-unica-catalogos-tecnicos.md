# Acción única en catálogos técnicos

Después de evaluar la vista previa embebida, cada documento técnico vuelve a
tener una única acción principal: **Ver catálogo**.

El enlace abre el PDF o visor externo en una pestaña nueva, desde donde el
usuario puede consultarlo, descargarlo o compartirlo. Se elimina el Dialog para
reducir decisiones, evitar duplicar acciones y mantener las cards compactas.
