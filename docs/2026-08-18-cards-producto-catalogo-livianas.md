# Cards de producto livianas en catálogo

`CatalogProductCard` adopta una jerarquía más editorial y menos decorativa para
facilitar la comparación dentro de grillas densas.

- La imagen se presenta a borde completo y conserva una superficie cuadrada
  estable.
- Se retiran sombras, elevación y radios grandes; el hover se limita al borde y
  a un zoom fotográfico mínimo.
- Nombre y precio mantienen la mayor jerarquía.
- Colores y cantidad de medidas comparten una fila simple, sin Badge para las
  medidas.
- La información repetida sobre alcance de promociones se reserva para la ficha;
  la card conserva su etiqueta promocional principal.
- El CTA ámbar sólido se reemplaza por una acción outline secundaria.
- Las pistas `sizes` reflejan la grilla de una o dos columnas en mobile y tres
  columnas junto al sidebar desktop.
- Skeletons y grilla replican la nueva geometría para reducir saltos visuales.
