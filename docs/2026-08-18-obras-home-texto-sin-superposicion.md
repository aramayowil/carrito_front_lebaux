# Obras de Home sin texto superpuesto en desktop

La composición editorial 1 + 2 conserva sus proporciones y jerarquía, pero el
contenido deja de superponerse sobre las fotografías. Cada card desktop utiliza
una estructura vertical con imagen flexible y una franja negra independiente
para tipo, título y especificación.

La composición aumenta moderadamente de `16/7` a `2/1` para preservar superficie
fotográfica después de incorporar la franja. Los títulos se limitan a dos líneas
y la obra principal reduce un nivel tipográfico. Mobile conserva su variante
vertical existente. El skeleton replica la nueva estructura.
