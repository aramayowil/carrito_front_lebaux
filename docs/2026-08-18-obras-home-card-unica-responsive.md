# Obras de Home con una única card responsive

La Home elimina la variante overlay de obras. Mobile y desktop utilizan ahora
exactamente la misma card vertical: fotografía 4:3 completa, información en una
franja negra inferior y acción “Ver proyecto”.

En desktop se reemplaza la composición asimétrica 1 + 2 por una grilla de hasta
tres columnas iguales. Una o dos obras se centran con anchos máximos adecuados.
Esto evita superposiciones y diferencias de geometría entre viewports. El
skeleton adopta la misma card única.
